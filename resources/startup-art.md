# 启动视觉

`startup-art.png` 是 2026-11-09 为 PointLab Studio 生成的位图素材，通过本次会话的内建图像生成工具创建。设计要点：深海军蓝背景，右侧青蓝色激光点云汽车、细线三维包围框与空间网格，左侧留白，克制的专业工程软件风格；素材不含品牌文字或进度。

软件以 `ui/startup.py` 实时绘制轻微背景移动、扫描光和呼吸光。品牌使用项目已有 `app.svg`；标题、版本、阶段文字与进度均由 Qt 绘制，保持清晰并反映真实状态。这是应用实时动效，不是预渲染视频，也没有为播放动效添加启动等待时间。

源码和 Windows 打包入口均使用独立、轻量的启动页进程，使主线程加载点云和显卡组件期间动画继续运行；Windows 通过专用管道传递实际加载阶段。启动完成或父进程结束时退出。若系统无法创建子进程，则回退到同进程启动页，阻塞导入期间动效可能短暂停顿。实际成品验收结果见 `docs/release-v2.0.0-fusion-2026-11-09.md`。

本 PNG 和 `app.svg` 为运行资源，请保留；生成过程截图、预览与验证脚本保存在项目外，位置见 `docs/cleanup-guide.md`。
