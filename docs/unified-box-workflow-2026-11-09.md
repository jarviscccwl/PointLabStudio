# 统一 3D 框选、播放恢复与启动体验

本轮在现有 `feature/recording-browser` 本地源码上继续改进，保留此前未提交工作。没有创建发布包、提交或上传 Git，也没有写入 D 盘原始采集数据。使用项目根目录 `start.bat` 体验；`dist` 中仍是原版 v1.3.0 EXE。

## 使用变化

- 顶栏统一为「3D 框选」。点云与同步图像下方直接显示三个调整视图，「参数」与「关联前后帧」按需展开；下方只保留一套播放/切帧控制。普通场景使用相同三视图，以实际三维体积选择、提取和删除点。
- 鼠标支持 Ctrl 拖选初始化三维框、拖中心平移、拖边/角调整尺寸、拖圆柄旋转、滚轮缩放局部视图、双击贴合。编辑区支持 WASD、QE、Shift 精调与局部撤销/重做。具体操作见主 README。
- 框包含中心、尺寸、yaw/roll/pitch，统一使用 `Rz(yaw) Ry(pitch) Rx(roll)`；旧工作区缺失姿态字段按零读取。手工编辑保留目标 ID 和原始帧索引，并成为不会被自动覆盖的人工锚点。
- 「更多」及左侧话题右键新增单话题重载。重载暂停播放，取消过期请求，等旧读取结束后清除对应话题缓存、重新读取并重建点云显示；保留当前帧、相机视角、同步设置、标定与标注。
- 生成的深蓝点云汽车素材配合实时扫描、呼吸光与轻微移动作为启动页。启动和加载进度只平滑绘制，真实进度值立即更新；未知总量显示流动状态，不伪造完成百分比。

## 点云停住的修复依据

根据用户描述「帧号或图像继续变化，但点云不动」，检查了实际呈现画面，而不是仅检查帧号。可复现的触发是 rendercanvas 2.7.2 的一次呈现初始化异常：调度器会继续等待完成通知，后续 `request_draw` 不能自行解除等待。

修复包括绘制异常后继续调度、成功绘制前保留待刷新状态，以及只在可见且有有效尺寸时检查绘制停滞。必要时使用公开同步呈现接口恢复调度；反复失败时提示并暂停播放。关闭窗口停止恢复定时器并处理已有呈现任务。单话题重载提供重新建立点云画布的入口。

不能据此保证显卡驱动永久失效、设备移除等所有外部故障都可恢复。原文件内容改变需要重新索引，不能靠显示重载绕过来源校验。

## 实现范围

相邻帧关联仍为局部几何关联，自动估计平移与水平旋转，不是语义检测或长时间遮挡重识别；保留手工 roll/pitch，尚未加入 IMU 自车运动补偿。需要人工检查自动建议。

三视图以源坐标轴投影，参照 SUSTechPOINTS 的常用操作，未嵌入该软件，也未复制其源码或原生标注格式。图像同步与已有相机参数功能保留。

点云处理库的首次导入必须保持主线程，以避免本机原生库与图形后端死锁。源码启动采用轻量 Qt 启动页子进程保持动画；冻结打包程序保留同进程回退，阻塞导入期间动画可能暂停。本轮没有打包，因此不将源码动效验收等同于 EXE 验收。
