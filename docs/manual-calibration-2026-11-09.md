# 手动内外参、标定包导入与融合导出

以下使用说明已同步标定编辑、区间与融合导出流程，并纳入 [v2.1.0](release-v2.1.0-2026-11-10.md)。文末保留上一轮手动内参工作的验证记录；其中的测试数量、截图与本机状态仅代表当时结果。

## 使用

从项目根目录 `start.bat` 运行源码，打开采集包后点图像上方「融合」。

- 「编辑内参…」可修改图像尺寸、fx/fy、cx/cy、skew、畸变模型及各系数。完整精度保留，参数校验通过后一次应用并刷新；取消或恢复打开时的值不会影响原始文件，外参保持不变。
- 「编辑外参…」在已有内参后可用，支持平移与旋转角、4×4 矩阵两种方式。窗口统一为雷达 → 相机光学坐标，`p_camera = R × p_lidar + t`；平移沿相机 X/Y/Z 轴、单位为米，旋转角单位为度。内参保持不变；无外参时输入为空，不自动应用单位矩阵。
- 角度采用右手系固定轴 XYZ，依次绕 X、Y、Z 轴旋转，`R = Rz(偏航) × Ry(俯仰) × Rx(横滚)`。俯仰 ±90° 时显示偏航为 0 的等价解。仅打开、切换方式或只改平移时保留原旋转矩阵精度。矩阵须为有限数值，最后一行是 `[0, 0, 0, 1]`，旋转正交且行列式为 +1；校验失败时提示修正，不应用到当前参数。
- 「导入标定…」支持 JSON、ROS/OpenCV YAML、TXT/CSV 矩阵、TOML、NPY/NPZ 和 ZIP。分别选择内参与外参，未替换部分继承当前值。已有内参时，只带在外参文件中的 K 默认不覆盖当前内参；仍可主动选择替换。支持只含 D、分辨率等字段的局部修正文件。
- 无说明矩阵必须先选择类型。3×3 内参需要确认标定图像宽高；3×4 或 4×4 外参需要指定原始方向和米、厘米或毫米单位。不会按文件名或形状猜测用途。NPZ 支持命名参数数组，NPY/NPZ 不读取对象数组或 pickle 内容；TOML 支持标准标定字段和 Caliscope 相机段。
- ZIP 内的多个外参必须明确选择。标定板、说明 HTML 和不可识别文件显示在略过说明中；包内文件不落盘。混合 TOML/矩阵文本仅在结构、方向和单位明确时读取，缺失说明或重复参数冲突会提示修正。
- 应用后停止播放，清除旧投影读取任务并刷新图像去畸变、点投影、赋色和图像 3D 框。切帧、话题重载、交换左右视图不会重新覆盖手工标定。重新选择 CameraInfo 可恢复自动匹配。
- 「更多 → 保存标定…」导出有效参数及来源说明；「更多」还提供参数详情和清除标定。保存工作区保留修正值和来源。首次工作区的手工标定也纳入未保存提醒；尚未加载采集数据的标定也可保存重开。

用户提供的 `内外参标定.zip` 中，说明文件指定当前使用：

| 参数 | 文件 |
| --- | --- |
| 内参 | `相机内参/camera_intrinsics.yaml` |
| 外参 | `雷视外参/jy_extrinsics.yaml` |

`radtan5` 映射到五参数 `plumb_bob`，不会丢弃 k3。`jy_extrinsics.yaml` 的正向、逆向和重复矩阵经过数值一致性核对，保留原始精度。其源文件没有整体验收状态；另外两份外参的候选、验证失败等标签仍在导入预览中展示。能导入和显示投影不等于外参精度已验收。

包内 `雷视外参/initial_extrinsics.txt` 是初始参数候选，当前可读取其 `[cameras.2]` TOML 内参段，以及明确注明 `T_camera_lidar` 方向的旋转、米制平移和 4×4 矩阵。重复外参必须一致，预览会提示核对版本；它不作为最新默认内参。只选择其中的外参时，当前内参保持不变。使用包内说明指定的当前组合时，仍选择上表两份文件。

## 时间轴与融合导出

先调整同步、标定、融合开关和点云视角，再点播放条「选择区间」。拖动「起」「止」手柄或输入起止帧，区间包含首尾；定位滑块和选区互不影响。时间轴聚焦后用 `Tab` 切换定位、起点与终点，方向键调整，`Esc` 返回定位。连续浏览会提前准备邻近帧，参数修改后使用新配置计算显示结果。

点击「导出」，选择「时间轴选区」「当前帧」或「全部帧」，核对帧数并选择格式。帧号对应当前主数据流的导入范围；「全部帧」不会扩大到尚未导入的原始范围。默认输出点云＋图像同步双窗格 MP4，也可选单独投影图像、点云画面、GIF、PNG 逐帧画面、PLY/PCD 逐帧点云或 PNG＋PLY。

画面包含已启用的去畸变、投影点和 3D 框，保持开始导出时的点云视角。单独图像 PNG 保留原图尺寸，单独点云画面 PNG 保留窗格像素尺寸；双窗格 PNG 和动画采用所选尺寸。投影最多采样 50,000 点，与预览一致。MP4 使用 `mp4v` 恒定帧率；GIF 受 10 ms 帧间隔精度限制，最高 100 帧/秒。动画按设置速度播放，不按原始时间戳间隔变速；无匹配图像时显示空白占位，不复用上一帧。

点云文件保存源坐标和字段，不受投影采样上限影响，也不把高度、强度显示色带写入 RGB。有可用标定和匹配图像、且开启图像赋色时，只覆写有效图像点的 RGB；其余点保留源 RGB，无源 RGB 时使用中性灰。附加 `image_color_valid` 标记本帧图像赋色是否有效（1 为有效、0 为原 RGB 或中性灰）；没有可用图像赋色时保留源点云字段。原始采集文件不变。

选择保存位置后，会新建结果目录并附 `manifest.json` 和 `frames.jsonl`，记录范围、设置、每帧来源、时间戳、实际标定与框。界面及 `position` 从 1 开始，源帧 `index` 从 0 开始。导出支持取消，结束后恢复浏览位置与视角；完整写入后才发布目录，取消或失败不会把不完整批次显示为成功。下拉菜单的主视图/对照视图当前内容导出也会保存当前图像中的投影和框；文本、表格仍导出当前页。
