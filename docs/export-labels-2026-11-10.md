## 使用变化

- 导出窗口点「命名并保存…」，可自定义文件名。GIF/MP4 只生成所选单文件；单帧 PNG/PLY/PCD 同样直接保存。多帧使用名称加浏览帧号，不另建目录或附加 JSON。PNG＋PLY 只在用户选择该组合时生成两种文件。
- 3D 框编辑栏增加「类别」，常见类别可直接选，也能输入自定义文字并按 Enter。类别随目标 ID 跨帧保留，重框不丢失；名称仍可独立修改。点云框和图像投影框均显示类别。工作区及单独导出的标注 JSON 保留类别；旧工作区显示未分类。
- 「提取框内点」右侧菜单 →「导出有框帧点云…」可自定义名称并选择 PCD/PLY，多帧追加原始帧号，只有一帧时使用输入名称。空框跳过；空框位置已有旧同名文件时整批停止，提示换名称或调整框，避免把旧文件当作本批次结果。
- 主点云切帧时清除旧屏幕框选高亮；完成建框时也释放该副本。当前帧的 3D 框高亮重新取自当前点云。类别和 ID 的延续属于正常关联，旧帧点云不应叠加保留。没有关联框的帧清空对应框与三视图。

## 修复依据

屏幕拖选高亮曾复制选中点形成独立绘制对象。`set_entities` 更换帧、以及完成 3D 建框时没有释放它，导致旧选点留在主视图。新增回归测试先复现旧对象仍在场景中，再在这两个生命周期边界清除选择运行状态。单纯更新 3D 框仍不干扰普通屏幕选点功能。

复核还修复了类别输入途中被切帧刷新覆盖的问题。用户正在修改同一目标类别时保留输入，提交后刷新规范化文字。所有导出先完成编码，再保存结果；覆盖前确认，取消或失败回退已发布文件。若文件系统拒绝回退，保留备份并报告位置。
