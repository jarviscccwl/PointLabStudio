# 融合浏览与交互优化

本文保留本轮融合功能在源码阶段的实现与验收记录；文中的“未打包、未上传”描述均指当时状态。后续 v2.0.0 成品与源码交付结果见 [融合版发布记录](release-v2.0.0-fusion-2026-11-09.md)。源码仍可通过项目根目录的 `start.bat` 运行。

## 使用入口

| 操作 | 入口与行为 |
| --- | --- |
| 双窗格点云着色 | 点云上方「颜色」，或顶栏 `1–6`。可改色图、字段、固定范围、点大小；左右任意一侧都有效。 |
| 标定与融合 | 图像上方「融合」。选包内 CameraInfo 或导入 JSON/YAML 内外参。 |
| 点云显示到图像 | 开启「点云 → 图像」，可调整深度/高度/单色、不透明度与点大小，最多采样 50,000 点。 |
| 图像给点云赋色 | 开启「图像 → 点云赋色」。给已有点云的可见点赋 RGB；普通颜色选择可恢复原有显示。 |
| 三维框图像联动 | 默认勾选「在图像中显示 3D 框」，内外参与匹配帧就绪后生效。人工框实线、自动建议虚线。 |
| 时间同步参数 | 「显示设置 → 时间匹配」，调整时间基准、容差和对照偏移。 |
| 连续检查标注 | 三视图中 `PageUp/PageDown` 上下帧，`Ctrl+PageUp/PageDown` 上下有框帧，焦点保留以便继续修正。 |
| 点云异常恢复 | 「更多 → 重新加载当前话题 / 重新加载对照话题」，保留当前帧、颜色和标注。 |

颜色、字段、范围、点大小及融合选项随 `.pls` 保存。换到不同点云数据流时自动适应新视野，同一数据流逐帧浏览和话题重载保留视角。录制浏览时隐藏不可用的普通场景工具，回到场景后恢复。

## 投影边界

- 外参必须明确提供，采用雷达 → 相机光学坐标（X 右、Y 下、Z 前）；点坐标和外参平移使用米。导入格式及反向变换支持见主 README。
- 支持普通透视、rational 和 equidistant 鱼眼畸变、图像缩放、去畸变后的对应投影。框边跨近裁面和画面边缘时裁剪，并自适应细分曲线；不跨越 rational 畸变奇点连线。
- 图像赋色不生成未知深度、不覆盖原始点云字段。相机背后、画面外和同像素被前方点遮挡的点保留基础显示。遮挡判断来自点云的像素深度缓冲，无法识别雷达未采到的遮挡物。
- 尚未做 IMU 去畸变、滚动快门补偿或外参自动标定。真实对齐取决于标定精度、时间同步和运动情况。

## 连贯性改进

三维框图像层独立于原始图像，编辑时不重新读取帧或替换图像。点云端复用线框、标签、采样点及旋转后的局部坐标；三视图复用点成员缓存，目标/结果列表不再每次拖动重建。

三视图保持在固定的编辑区域，参数按需展开。窗口高度不足时，「参数 / 关联设置」使用独立小窗，三个编辑视图、关联按钮及上下框导航仍保留；收起编辑器后恢复完整预览空间。较长的状态提示在一行内显示，悬停可查看全文。

确定性 500,000 点基准中，选中框平移刷新中位耗时从 72.6 ms 降到 13.1 ms（p95：83.7 → 13.9 ms）；同帧目标切换从 52.5 ms 降到 4.6 ms。这是框编辑局部开销，不等于整段 PCAP 的解码或播放帧率。

启动页保留已有专业素材，以独立进程持续播放动效；未知工作量显示真实阶段与连续活动指示，不再编造 45/90/100% 阶段百分比。普通进度条从当前显示位置平滑接近实际值，首个数值和完成值也不瞬跳。若系统无法创建动画子进程，局部回退仍可能在重型模块加载时短暂停顿。现有 EXE 未重建，因此新启动路径在源码和模拟冻结入口验证。

Windows 系统强调色与软件主题不同时，忙碌指示和数值进度现在统一使用软件主题色。验证覆盖系统紫色，以及深浅主题下的 Windows 原生/Fusion 控件样式。
