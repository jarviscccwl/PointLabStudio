# 树木前后帧关联修复

本轮处理「选中树后关联前后帧没有结果」的问题。用户忘记了当时帧号，原有日志确认关联任务实际执行过，但返回了“匹配质量不足、0 个自动建议”；这不是只需要补充操作说明的问题。

修改保留在当前本地源码中，使用根目录 `start.bat` 启动。未打包 EXE，未提交或上传 Git；`dist` 中保留原版 v1.3.0。

## 原因与修复

原算法用最多 512 个源点配准，同时用这 512 个点检查最多 4096 个目标点的覆盖率。树冠较大时，抽样之间的空隙被误判为缺失几何。候选起点还全部将点的质心移到搜索位置，没有保留上一帧的实际框姿态；树干、树冠密度不均时，点的质心与框中心可能相差数米。

在用户的 114507 PCAP 中，中心 `(30, -4.5, 2.5)`、尺寸 `(6, 6, 8)` 米的树冠区域，修复前连同一帧与自身比较都可能失败。这是明确可重复的算法问题，但不能据此认定是用户当时同一个框。

现在仍用最多 512 个点做配准，以最多 4096 个源点验证质量，并明确保留上一帧姿态作为候选起点。对几何近似对称的树冠加入小幅角度连续性偏好，减少抽样噪声导致的半圈翻转。质量门槛仍为 0.65；目标丢失、位移超限、原始帧不连续等情况仍会停止，不直接复制旧框制造结果。

## 操作

1. 打开采集文件夹，点顶栏「3D 框选」，拖选树木，用三个视图调整框的深度和边界，尽量排除邻近树木、地面和建筑。
2. 直接点蓝色「关联前后各 5 帧」。方向、数量和最大位移在「关联设置」中调整，按钮文字同步显示实际范围。任务开始后显示进度，可取消；取消不会留下本次未完成批次的建议框。
3. 用「上一框 / 下一框」或有框帧下拉框逐帧检查。拖动三视图修正后即成为人工框，再次关联不会覆盖它。当前帧没有框时，用「返回有框帧」返回最近的已有框，或在当前帧「重框」继续关联同一目标。

「关联设置」只展开设置，启动关联的按钮独立显示。操作按钮、进度和状态不随三视图/参数区滚走；失败信息包含停止的原始帧号、原因和恢复方法。原始帧号在界面从 1 开始，导出 JSON 索引从 0 开始。
