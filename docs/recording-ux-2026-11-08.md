## 使用方式

- 打开 PCAP、MCAP 或 BAG 后，先选择要看的数据流。文件、话题的详细格式和时间信息通过“内容详情”展开，默认把空间留给列表。
- 主界面选择数据流即可浏览；开启“同步查看”后才显示对照选择行，完整话题和来源仍可通过提示查看。
- “浏览设置”独立显示时间匹配、相机内外参和投影设置，调整时可以继续观察预览。关闭或按 Esc 后，按钮状态同步恢复。
- 标定矩阵保留在“参数详情”中。只有当前图像、点云和外参可用于投影且已勾选“点云投影”时，才显示颜色、透明度和点大小选项。
- 拖动时间轴时暂停播放，松手后读取目标帧；时间偏移和容差输入完成后再触发更新。
- 默认状态区不再重复显示两套完整时间戳；精确时间仍保留在每个视图的“信息”中。匹配失败、读取错误和投影状态继续显示。
- 左侧数据源右键菜单和中央“更多”均可重新选择话题/范围或重新读取文件。重新选择时填入原有范围；按时间筛选保留并标明原导入起点。
- 更新索引后尽量保留当前原始帧、对照数据流和标定设置；取消和失败保留已有数据源。工作区原来的未保存修改不会被错误标记为已保存。
- 移除正在查看的主数据流或对照数据流后退出双视图，避免只剩一个流时无法关闭对照。
- 未匹配提示区分主/对照时钟缺失、空范围、超出容差与读取失败；超出容差会显示最近帧的实际时间差。
- 对照点云加入场景使用它自己的原始帧号，导出文件名处理 Windows 特殊字符。缺少外参时保留图像，投影控件显示缺失条件。
- 提高辅助文字的可读性，场景列表数量列只显示数据流数量，完整格式保留在提示和概览中。
- 修复关闭窗口后状态提示定时器仍访问已销毁控件的问题；关闭点云视口前取消并回收 GPU 图像下载，覆盖预览区折叠至零尺寸及重复停止。

## 实现范围

复用现有解码器、数据流选择、播放及导出逻辑；未改动 PCAP/MCAP/BAG 的解析协议和标定计算。修复了投影样式控件没有传到图像绘制端的问题，复用既有 projection_colors，并将样式纳入工作区保存和恢复。视口关闭使用 rendercanvas 2.7.2 的下载取消接口，requirements.txt 与 pyproject.toml 均固定为该版本；升级渲染依赖时需重跑关闭窗口回归。

读取提示保留固定布局空间，避免播放时预览高度反复变化。补齐浏览器背景及工具区域的主题切换，工具按钮可以通过键盘聚焦。
