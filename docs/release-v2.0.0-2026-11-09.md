## 本轮界面与功能整理

- 主视图、对照视图各占一行，同步关闭后隐藏对照行；较长的话题名不会把常用按钮挤出。
- 播放、切帧、速度、时间定位和导出集中在操作行，时间与匹配状态放在下方。底栏保留任务、缓存、FPS、日志和版本，减少重复信息，长文字自动省略。
- 数据包概览将浏览范围与底部操作分开；「统计准确帧数」在左下角，「加入浏览 / 取消」在右下角。取消概览后明确显示已取消，避免残留「正在读取」提示。
- 「3D 框选」统一进入三视图、手动修正与前后帧关联；关联结果可通过「上一框 / 下一框」或有框帧列表查看。
- 修复点云成功恢复显示后仍累计故障、误报并暂停播放的问题；连续呈现失败仍会提示。单话题重载保留浏览上下文。
- Windows 包补齐动态 ROS 类型库和消息序列化依赖，修复成品中图像、相机参数因缺少 `rosbags.serde.primitives` 而退回原始消息的问题。

## 建议的操作流程

1. 打开或拖入整个采集文件夹，例如 `D:\2026_10_14\selective_20261014_114507`。
2. 在概览中查看数据源、话题类型和数量；需要准确 PCAP 帧数时点击「统计准确帧数」，再选择内容加入浏览。
3. 选择 PCAP 点云为主视图、MCAP/BAG 图像为对照视图，使用「同步查看」。时间基准、容差、偏移和相机设置集中在「浏览设置」；切换到尺度不同的数据后，可点击预览上方「适应」重新居中。
4. 点击顶栏「3D 框选」，在已有框所在帧选择目标，点击「关联前后各 5 帧」。用「下一框」逐帧检查，并在俯视、前视、侧视图拖动修正；修正后变为人工框。
5. 用 `Ctrl+S` 保存工作区。若某话题显示异常，使用「更多 → 重新加载当前话题」或「重新加载对照话题」。

完整三视图编辑建议使用约 1280×850 或更大的窗口。约 1024×700 时常用按钮仍可操作，编辑器和展开的参数区通过内部滚动查看。

## 使用范围与边界

本次交付与真实桌面验证针对 Windows x64；不代表 Ubuntu 或所有显卡、所有厂商 PCAP 协议、所有消息编码均已验证。原始/压缩图像等能力取决于已有格式解码器，未知或不支持的消息可查看原始信息。树木关联为相邻帧几何建议，人工修正仍需保留；匹配不足时会停止并给出原因。

播放会根据实际读取速度推进，大文件不保证达到所选帧率。本轮确认修复了显示恢复成功后的误报暂停，并没有把所有底层调度迟滞归为已解决的问题。
