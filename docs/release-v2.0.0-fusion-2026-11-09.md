- 文件夹与 PCAP、MCAP、BAG 的内容概览、按时间同步浏览点云和图像，以及图像、相机参数、IMU、文本和表格查看。

## 使用范围

本次成品针对 Windows x64。真实采集包暂时没有雷达到相机外参，因此融合几何使用已知标定样例验证；真实投影对齐仍需导入对应标定结果。示例标定不能套到真实采集包。

自动关联基于相邻帧局部几何，需要人工检查，尚未进行 IMU 自车运动补偿或跨长时间遮挡重识别。播放速度受实际解码和显卡性能影响。
