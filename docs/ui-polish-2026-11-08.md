# 界面与交互优化验证记录

## 本次改动

- 调整点大小仅更新显示数值与渲染材质，不重复计算概览统计、颜色直方图。
- 表格搜索合并 150 ms 内的连续输入；Enter 立即筛选，换页立即应用当前条件。
- 表格采用主题配色、交替行底色、像素滚动；统一输入选中态、禁用态、表头和复选框图标。
- 图像缩放支持触控板细小滚动，横向滚动不触发缩放，缩放比例限制为 0.01–64。
- 参数弹窗使用自适应表单、中文操作按钮和可访问名称。
- 修复数据浏览器缺少标定保存/重置方法导致的主窗口创建失败；保存使用 QSaveFile 原子提交。
- 标定面板接入实际数据状态；切换主题同步更新图像背景和标定面板。
- 修复对照视图导出与交换视图的帧索引，并恢复相关按钮的就绪状态。
- 本机虚拟环境重建启动器，保留已安装依赖，修正失效的旧 Python 路径。
