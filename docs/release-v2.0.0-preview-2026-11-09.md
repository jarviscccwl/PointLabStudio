## 新增功能与源码

三视图底部「提取框内点」将当前框内的完整点云加入场景，可继续处理、导出、撤销和重做；右侧箭头提供「批量提取有框帧到文件夹…」，逐帧输出 PCD 与时间戳清单。字段精度、空框行为、取消和数据坐标的说明见 [框内提取与性能记录](box-extraction-performance-2026-11-09.md)。

三视图绘制采用 Qt 原生批量转换，优化框内高亮、点云范围计算、MCAP 读取器复用和 EM4 解码，关联算法按需加载。保留 Python/Qt 框架；同条件下框调整约从 77 ms 降至 25 ms，不把局部计时等同于所有机器的保证帧率。

GitHub 分支通过官方重命名接口从 `feature/recording-browser` 改为 [`preview`](https://github.com/jarviscccwl/PointLabStudio/tree/preview)，保留原有提交历史。源码交付包括程序、测试、资源、说明和构建配置；EXE、`dist`、虚拟环境、原始采集数据及本机验证副本不上传。`main` 保持不变。
