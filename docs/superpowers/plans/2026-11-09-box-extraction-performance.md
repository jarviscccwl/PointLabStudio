# 3D 框提取与播放性能

目标：采集包当前帧的 3D 框可以直接提取为独立点云；减少真实 PCAP + MCAP 双窗格浏览的等待与界面阻塞。

## 交互与边界

- 在现有三视图编辑器中增加“提取框内点”，不增加新面板。可通过已有“上一框 / 下一框”切到关联帧后提取。
- 按当前完整分辨率数据、三轴旋转框判断，保留源坐标、所有字段及显示设置；提取结果不与源数据共享可变数组。
- 后台提取，可取消；空框不新增实体。加载中、无框或源文件变化时拒绝操作，取消及失效任务不落地。
- 结果进入场景，支持撤销/重做、现有导出与项目保存；记录源文件、话题、原始帧号和时间戳。
- 用户补充：需要当前帧与关联多帧提取。批量按每帧独立 PCD 加清单导出到用户选定目录，逐帧处理限制内存；取消/失败不留下不完整输出。
- 用户确认卡顿集中在启动、旋转视角、调整 3D 框；增加对应测量与优化，优先减少三视图重绘中的 Python 对象创建和启动时无关模块加载。

## 实施顺序

1. 完成干净基线：同一真实包、同一帧区间、同一颜色模式，记录读取、显示准备与双窗格帧间隔。
2. 先补提取的几何/字段/取消测试和 UI 落地测试，再接入后台任务及按钮。
3. 优化已定位的重复工作：MCAP reader 生命周期复用（锁、关闭、失效、取消），常规压缩图像避免重复数组复制；测量点云边界计算与 EM4 原生 NumPy 批处理的改进。
4. 运行相关回归、同条件性能对比和真实窗口验收；仅当必要且有收益时再考虑自建 C/C++ 模块。
5. 整理使用说明、性能结果与可清理路径。保留现有 EXE，不自动打包或推送本轮改动。

## 技术选择

保留 Python + Qt 界面和现有原生 NumPy/Open3D/渲染库。基线显示有重复解析、数组复制和显示准备开销；没有证据支持整套 C 重写能改善更多且不引入功能回退。按热点消除重复工作，使用实测决定进一步原生加速范围。

## 验证

- 旋转框、边界/非有限点、超过显示采样上限、字段与显示参数、独立数组、空结果/取消。
- 未完成读取、无当前框、源变化、取消、关闭与场景撤销；原始帧号不混淆。
- MCAP 重复时间戳、缺少摘要/定义、并发读取、关闭重开、源变化；JPEG/PNG/深度/透明图像保持行为。
- 不用易波动的耗时断言判定测试；保留真实数据对比证据与限制。
