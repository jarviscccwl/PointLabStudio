# 手动修正内参与标定包导入

基线：origin/main `aaa0a90`。在现有“融合”入口扩展，不改变主工作区布局。

1. 支持安全读取 OpenCV YAML、radtan5、明确方向的正逆外参，重复表示必须数值一致。ZIP 在内存中读取，区分标定板与标定文件，展示文件自带候选/验证状态。
2. 导入窗口分别选择内参与外参，未替换部分继承当前值，避免外参附带的内参覆盖手动修正值。多组外参必须由用户选择，不按文件名猜测精度。
3. 增加内参编辑器：分辨率、焦距、主点、skew、畸变模型和系数；校验后一次应用，可取消或恢复打开时的值，外参保留。
4. 应用后停止播放并刷新投影、赋色和图像 3D 框；采用现有读取代次机制拒绝旧结果。保存项目和导出参数均保留有效修正值及来源说明。
5. 先添加解析/编辑/融合回归，验证真实压缩包与真实点云图像组合，并检查原生窗口。更新使用指南，过程证据放项目外。

用户提供的说明指定 `camera_intrinsics.yaml` + `jy_extrinsics.yaml`；仅用于验证导入与计算流程，不将数值一致性描述为外参精度验收。本轮不打包、不上传、不改动原始数据。
