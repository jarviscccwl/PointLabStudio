# 整体使用体验检查与完善

用户希望在现有功能上达到专业、便捷、清晰、顺畅，并同步整理文件和根 README。本轮保留 Qt 桌面、蓝灰配色、深浅主题、现有功能入口，以使用任务为中心精修，不引入新的视觉风格或依赖。

## 检查范围

从空工作区和采集目录概览，到点云/图像同步、标定修改、3D 标注、区间导出完整检查。已知问题优先修复：同时打开编辑器和导出区间时预览面积不足，图像边缘标签被截断，以及发现的具体操作反馈和输入问题。加载和切帧使用已有后台读取与预加载，避免用装饰动画掩盖真实等待。

## 目标与边界

- 默认分配足够的主预览空间，三视图完整可操作；手动调整分隔条后尊重用户尺寸。
- 标注类别和编号在图像边缘仍可读；拥挤空间使用省略和悬停说明。
- 导入、标定、导出的确认与错误明确说明下一步，不能丢弃已输入参数或悄悄改变选择。
- README 按实际操作流程说明当前源码能力，明确尚未重新打包的功能，保留已发布版链接。
- 本轮不打包、不提交、不上传。保留此前改动，原始采集包和标定文件只读。
- 历史清理被拒绝的目标不以其他方式重试；新过程材料集中存放项目外，无法清理时提供清单。
