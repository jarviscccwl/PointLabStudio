# 点云、图像与三维框融合浏览

## 使用目标

加载采集文件夹后，在同一个工作区完成同步浏览、点云着色、标定投影和三维框逐帧修正。减少常驻参数；保留现有 Qt / pygfx 架构及所有已有数据读取能力。

## 实施选择

沿用双窗格，在现有浏览设置中增加清晰的“点云显示 / 融合”入口。相比另开融合窗口，这能保留时间匹配、视角和标注上下文；相比重写整个界面，风险和迁移成本更低。此为实施判断，用户已要求直接修改并测试。

- 两侧的点云均可切换着色模式、色图、标量字段与范围。切帧、话题重载和工作区恢复保留显示偏好。
- 融合包含：点云投影到图像、图像给已有点云赋 RGB、三维框投影到图像。单目图像不生成未知深度。RGB 只覆盖相机可见点，视野外保留基础颜色，像素遮挡优先最近点。
- 标定明确采用雷达 → 相机光学坐标的刚体变换，长度单位米。继续支持 Brown / rational / fisheye 畸变及图像缩放。去畸变图像上的点与框采用对应无畸变投影。
- 图像框为独立绘制层，编辑、选中、删除和切帧实时刷新；穿越近裁面、画面边缘的框不能消失或出现错误连线。
- 点云、图像匹配与外参缺失时明确提示；不猜测真实外参。现有 D 盘数据只读。
- 关联帧保留人工框和取消语义，优化重复计算、导航和提示，不伪称具有语义识别能力。
- 启动采用连续活动动效和真实阶段信息，平滑过渡；未知工作量不显示虚构百分比。已有加载进度同样平滑。
- 视觉延续现有浅/深色主题，以留白、对齐和按需展开简化操作，不增加装饰性动画。

## 验收

自动回归覆盖双窗格着色、标定投影几何与遮挡、图像框同步、状态恢复和关联流程。使用 114507 实际采集包检查颜色、逐帧/播放、框编辑、重载与窄窗口。真实标定未提供时，投影对齐仅以已知几何样例验证，并在交付中说明。
