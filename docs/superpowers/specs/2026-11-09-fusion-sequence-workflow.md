# 标定、融合导出与连续浏览

用户希望完整的内外参修正、多格式导入、投影结果导出、帧区间选择及动画，同时改善大文件夹导入和键盘连续浏览。已确认动画默认是同步点云＋图像双窗格 MP4，保留单窗格、GIF、逐帧文件选项。

沿用现有 Qt 桌面与 pygfx 显示，不另建一套软件。采用渐进显示：融合参数集中管理，时间轴平时用于定位，打开区间选择后显示起止手柄；导出窗口统一当前帧、选中区间和输出内容。

内外参编辑使用清楚的单位与方向，允许平移/旋转与矩阵修改，校验后应用。导入支持现有 JSON/ROS/OpenCV YAML/ZIP，并增加常见文本表格、TOML、NumPy 形式；不猜测无方向矩阵，明确选择方向及单位。文件附带内参不能默认覆盖手工值。

导出显示结果与点数据分开选择：投影图像包含当前投影点与图像框；赋色点云保留实际坐标与 RGB；动画按当前视角、融合开关与同步配置逐帧生成，写入内存有界，包含范围和时间戳清单，失败/取消不留下冒充成功的输出。无匹配图像不可沿用上一帧。

预加载与当前读取使用同一串行读取通道，避免多个线程共享源解码器。相邻帧提前完成解码及融合计算；缓存有内存上限，配置/数据源变化失效，当前导航优先。连续按键合并请求，不重置视角，不以旧云对应新帧号。

大文件夹的发现、概览和索引提供可取消阶段与明确数量；避免同步磁盘遍历卡住主窗口，已存在索引复用。外观保留现有深浅主题与字体，收敛按钮、长文件名和次要说明。

不改动原始数据，本轮不打包或上传。真实数据、内外参 ZIP、导出后的独立解码、取消/关闭与已有功能回归均须验证。过程产物放项目外，历史被拒绝的删除不重试。
