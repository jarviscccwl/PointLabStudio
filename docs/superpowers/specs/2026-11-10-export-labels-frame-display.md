# 文件导出、目标标签与逐帧显示

## 用户目标

- 保存时可自定义名称。GIF、MP4 或单帧数据只生成所选文件，不创建结果文件夹或附加清单。
- 3D 框可指定类别，保持稳定目标编号；关联帧继承同一目标类别，允许逐帧调整几何。
- 切帧只显示当前帧的点云和框。目标类别、编号持久保存，旧帧点云及屏幕选点高亮不残留。

## 交互约定

导出先选内容和范围，再使用文件保存对话框命名。多帧 PNG/PLY/PCD 以用户输入名称为前缀追加帧号，直接保存在所选位置；只有显式选择组合格式时才生成两种文件。覆盖已有文件需明确确认，失败或取消保留已有成品。

框编辑常驻显示可输入自定义类别的下拉框，提供汽车、卡车、公交车、行人、自行车、摩托车、树木等快捷类别。类别属于目标，名称继续独立可改。主视图和图像投影显示类别、名称/编号；旧工作区兼容为未分类。

不删除关联框作为残留问题的规避方案。检查屏幕选点高亮、主云、三视图和图像投影的生命周期，以真实切帧验证。未关联到的帧不显示上一帧框。
