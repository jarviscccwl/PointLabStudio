# 统一 3D 框选、播放恢复与启动体验

用户要求直接继续实现：将目标跟踪并入框选，使用类似 SUSTechPOINTS 的 3D 框与三个调整视图；修复「帧号/图像继续而点云不动」，增加话题重载；精简界面；用图像生成设计启动视觉并配合流畅动效和进度；整理文件。沿用既有源码目录，不打包、不提交、不上传、不写原始数据。

## 选择与范围

采用现有 Qt / pygfx 架构中的统一 3D 框工具，三个轻量正交视图使用 Qt 绘制，复用已有标注与几何关联。另一方案是嵌入整个 SUSTechPOINTS 网页，涉及独立服务与数据转换，会造成两套数据状态；完全更换渲染器也无法直接解决现有流程问题。这是实现者依据当前项目作出的选择，用户已授权本轮实现，无需为可逆本地修改重新审批。

参照 SUSTechPOINTS 官方操作说明：https://github.com/naurril/SUSTechPOINTS/blob/master/README.md 。参照交互方式，不复制其源码或宣称功能完全等同。

## 3D 框选

- 保留顶栏一个「3D 框选」入口，移除采集浏览条中独立「目标跟踪」入口；关联前后帧成为同一面板中的操作。
- Ctrl + 左键拖动或工具内新建，用屏幕矩形初始化有深度的三维框，随后实际选择、调整和提取以三维体积为准；不是长期使用屏幕矩形筛点。
- 同步显示俯视、前视、侧视中的框内与附近点。三个视图可拖中心平移、拖边/角调整尺寸、旋转；W/A/S/D 移动，Q/E 旋转，Shift 精细调整，双击边/角/中心贴合框内点，提供撤销。所有操作仅在编辑视图有焦点时生效。
- Box3D 增加 roll、pitch，保留 yaw 为第三个位置参数以兼容旧代码。旋转约定 Rz(yaw) Ry(pitch) Rx(roll)，源坐标系，米/弧度。旧标注缺少 roll/pitch 时默认为零；跟踪只估计平移与全局 Z 增量，保留手工 pitch/roll。
- 普通场景的框选也使用同一三视图编辑器，按三维框重新计算选中点；保留提取/删除选中点的原有非破坏性处理。
- 录制框保留目标 ID、原始帧号、人工锚点、源身份校验与保存恢复。编辑器切帧立即禁用，杜绝旧帧改到新帧；切帧恢复对应三维框。
- 编辑内容嵌入浏览区域，参数与关联折叠/分组，关闭面板恢复大预览；保留同步图像。

## 播放与恢复

先检查真正的点云刷新和绘制链，增加可复现的渲染失败/隐藏恢复/连续帧检查。绘制异常不能默默终止后续调度；瞬态失败重试，持续失败应明确提示。显示状态以成功绘制为依据，不能把帧号变化当作点云已显示。

在话题的操作菜单提供「重新加载当前话题」和对照话题重载。暂停播放、取消过期读取，等待当前读者退出后清除该话题缓存，恢复当前原始帧与同步/标定/标注，重新读取和刷新显示。不能同时从同一个数据源启动第二个读取，不能清除其他话题的标注，也不能卡住后强杀线程。源文件改变沿用原有失效规则，另保留整包重新索引入口。

## 启动与加载

生成专业克制的深蓝点云/三维框启动背景，文字、品牌图标和真实进度由 Qt 绘制，动画轻量循环且不人为延长启动。图像工具负责视觉素材；运动由应用绘制，可随启动状态结束，不把静态图片称作生成的视频。

进度展示平滑追随真实值，未完成不提前到 100%；未知总量使用持续流动的忙碌状态；取消、隐藏、关闭停止动画。长时间导入阶段需保证启动动画事件循环能继续运行，禁止在非 GUI 线程构造 QWidget。全应用加载对话框与概览采用统一进度组件。
